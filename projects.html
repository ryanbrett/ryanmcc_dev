signai.ryanmcc.dev — Generative AI Sign Mockups & Parametric SVG Engine

https://signai.ryanmcc.dev

A generative web application engineered to accelerate industrial signage and commercial fabrication estimating. Users describe sign requirements in natural language; the system parses the prompt, auto-populates a structured parametric specification form (dimensions, substrate types, lighting styles, mounting hardware, and typography), and generates an editable, precision-scaled SVG mockup with one-click export pipelines for customer proofs and production pre-press.

Explore the active beta at signai.ryanmcc.dev ↗.

floor.ryanmcc.dev — Spatial Layout & Yield Engine

https://floor.ryanmcc.dev

Typst Dynamic Variable Resume

https://github.com/ryanbrett/resume/

A dynamic, code-driven resume document system built with Typst. Instead of wrestling with static layout applications or fragile markup, this system uses programmable Typst code to generate variable-driven, pixel-precise document outputs with custom typographic hierarchy and modular data structures.

Source code, typographic templates, and build configuration available on GitHub. If you would like a direct copy of my resume, feel free to reach out.

Compliance & Safety Signage Engine

An automated web application and workflow system for industrial signage and pharmaceutical-grade safety labeling at Vulcan Inc. The system enforces strict adherence to federal OSHA 1910.145, ANSI Z535 visual warning standards, and state AMCC packaging rules.

It eliminated manual design mistakes on critical industrial safety panels and achieved a verified 100% regulatory audit pass rate across active production facilities.

VBA Generative Data-Merge Engine

Custom automation software engineered to handle high-volume variable data merging for large-scale production manufacturing. It directly parses complex customer spreadsheets and programmatically generates imposition-ready vector layouts.

This reduced variable data job setup from 14 minutes down to 3 minutes per unit, producing over $23,000 in verified annual labor savings while eliminating manual data entry errors.

Kongsberg CNC & Routing Pre-flight

Internal vector pre-flighting script suite designed for Kongsberg digital finishing tables. Programmatically validates registration marks, kerf compensation offsets, and tool assignment layers (beveled knife, router bit, crease wheel) prior to physical cutting.

Reduced machine downtime and scrap substrate waste across high-density acrylic and aluminum composite panels.
